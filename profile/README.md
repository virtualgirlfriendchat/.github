3. Model Selection. The prompt is routed to fine-tuned open-source models designed specifically for creative roleplay and romance.

5. Context and Memory Injection. The system injects previous context so the AI remembers the established boundaries, preferences, and relationship history.
6. Final Output. The generated text is delivered to you, seamlessly continuing the fantasy.
